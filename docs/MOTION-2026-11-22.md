# Reel-inspired dashboard motion

Direct request: take animation inspiration from https://www.instagram.com/p/DfrtgFyTmOM/ (code.xr, Ember Dashboard V29). The reference was opened and its circular opening and page/card transitions were visually inspected. The existing v86 palette and slower pacing are retained.

- One 950ms circular opening reveal using a native view-transition snapshot of the content workspace. The readiness event runs after initial routing, without waiting for saved data or making new requests.
- Individual cards enter with the existing 700ms cadence and capped 210ms stagger, with a small settling motion. Parent grids and their cards never receive compounded movement.
- Eligible cards lift 3px on desktop hover over 320ms.
- Navigation remains synchronous. Rapid changes cancel pending entrances and skip an opening in progress. Saved Motion off, reduced motion and hidden pages remain authoritative. Browsers without View Transitions retain the existing card cascade.
- Maps, canvases and embedded charts keep stationary ancestors; no persistent masks/transforms, number tweening, new libraries, or paid calls.

Verification: 270 project tests passed; production build passed. Cloud browser QA used same-origin preview frames at actual 390px and 1440px viewport widths. Both reported no document overflow and observed the native iris CSS animation; its temporary class was removed on completion. Tested Overview, Investments, News and Career navigation, including rapid changes. Saved Motion off produced zero opening/card animations. Desktop hover computed to translate(0, -3px), with a 320ms transition. OS reduced-motion and unsupported-API paths were covered by deterministic tests, not by changing browser OS preferences. Preview used empty local data, not production recommendations. The only observed console error came from the browser extension, not dashboard code.

The temporary QA page was removed before the production build. No GitHub, bdashh.com, settings, schedules or saved data changes are part of this release. No Orbital private patch was included.

RECORD INTELLIGENCE

Make this command centre yours

Public viewing, protected editing. When this Site is public, visitors can read its saved portfolio, briefings, workbook records and maps. Only the signed-in owner and authorized scheduled updates can save changes. Local file imports stay in this tab until explicitly saved. No brokerage passwords or account access are bundled.

1 · Your data, locally

Download the blank Brian’s Dash workbook with four new tabs: Coursework, Daily Planner, Holdings, and Stock Research, plus the original career and event trackers. Load your own .xlsx, or import a positions CSV from the Investments page. Imported workbooks initially stay in this tab. Use Save workbook to dashboard to sync them across devices, or Export workbook for a local copy.

Demo names and events are fictional. Demo map pins use public California landmarks, never someone’s residence.

2 — Your connected accounts

This dashboard runs independently. Import workbook and positions files here. Email, calendar and brokerage accounts are not connected; any future integrations require their own authorization.

3 — Daily stock news & research

Use Owner tools to refresh news and AI career research. Scheduled updates become available after configuration and testing.

4 · Maps and locations

The default view centers on Irvine and Riverside. The route origin is a public Irvine reference point, not your home. Adjust it yourself for optional driving estimates. Tactical map, café search, address lookup and optional Cesium photorealistic viewer remain included, subject to providers’ own terms.

Advanced (not recommended): read an intentionally public Google Sheet

Optional public sheet feed

Only use a sheet that can safely be read by anyone with the link. This is not appropriate for private financial holdings, contacts, emails or coursework. We do not change its sharing settings.

The link stays only in memory until the tab is reloaded. This feed is read-only; drafts do not sync.
